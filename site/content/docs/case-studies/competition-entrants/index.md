# Competition entrants

`zz` is one entry in Cloudflare's ["next git platform"](https://blog.cloudflare.com/next-git-platform-on-cloudflare/) competition. Other entrants are solving overlapping problems, sometimes in genuinely different ways, and reading them closely is worth doing properly rather than dismissing on sight -- a real, shipped system that made a different tradeoff is evidence, not just an alternative opinion. Each entry below is evaluated the same way: what problem it's actually solving (which isn't always the same problem `zz` solves, even when the pitch sounds similar), where the overlap is real, what it validates or challenges about `zz`'s own choices, and what's specifically worth taking -- never a wholesale adoption, since the point is synthesis, not benchmarking against a leaderboard.

This collection grows as more entrants turn up.

| Entrant | What it's actually solving | Worth taking |
| --- | --- | --- |
| [AI Rodeo](/docs/case-studies/competition-entrants/airodeo/) | Best-of-N single-owner change approval (several models race the same request, a judge scores them, the owner clicks yes/no) -- an adjacent problem to `zz`'s multi-party coordination, not the same one. | Structured, auto-verifiable checks as a companion to a task's plain-English description; per-request token/cost transparency. |
